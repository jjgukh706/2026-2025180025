애니메이션 뷰어 기획 초안

pico2d 사용

python 사용

단일파일로 이름은 sonic_animation_viewer.py
이 때 사용하는 sprite sheet는 sonic-sprite.png

기능:
1. spritesheet에 있는 모든 애니메이션을 재생 (10종 동작, 총 76프레임)
2. 한 동작의 애니메이션을 5번 반복 재생, 1초 쉬고(정지), 그 다음 동작으로 간다.
3. 전체 애니메이션 재생이 끝나면 다시 무한반복한다.
4. 이미지의 크기는 화면에서 잘 보이도록 한다 (4배 확대 출력).

구현절차:
- 한 번에 모든 코드를 작성하지 말고, 개발 단계마다 커밋을 추가하며 최소한 20개 이상의 커밋이 추가되도록 한다.
