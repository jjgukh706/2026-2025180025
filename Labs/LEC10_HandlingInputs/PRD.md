# [PRD] 소년 상하좌우 이동 및 방향 바꾸기 개발 문서

---

## 1. 개요 및 목적

* **프로젝트명**: LEC 10 소년 이동 및 방향 전환 (Boy Movement with Direction Change)
* **목적**: 방향키(상하좌우) 입력을 받아 소년 캐릭터를 화면에서 이동시키고, IDLE/이동 상태와 좌우 방향 전환을 처리하며, 화면 끝 경계에서 더 이상 이동하지 않는 동작을 pico2d로 구현/검증한다.
* **개발 언어 및 도구**: Python, pico2d
* **작업 대상 파일**:
  * 단일 소스 파일: `boy_movement.py`
  * 스프라이트 시트: `animation_sheet.png` (크기: 802 × 402 px, RGBA)
  * 배경 이미지: `TUK_GROUND.png` (크기: 1280 × 1024 px, RGBA)
* **개발 방식**: 점진적 개발 — 모든 코드를 한 번에 작성하지 않고, 개발 단계마다 단위 커밋으로 기록한다.

## 3. 사용자 시나리오 및 기능 요구사항

### 3.1 사용자 시나리오

1. 프로그램을 실행하면 800 × 600 캔버스가 열리고 배경(`TUK_GROUND.png`)이 그려지며, 소년이 초기 위치(화면 중앙)에서 **IDLE 애니메이션**을 재생한다.
2. 사용자가 **좌/우 방향키**를 누르면 소년이 해당 방향을 바라보며 **이동 애니메이션**으로 왼쪽/오른쪽으로 이동한다.
3. **상/하 방향키**를 누르면 소년이 **기존에 바라보던 좌우 방향을 유지한 채** 위/아래로 이동한다.
4. 방향키를 놓으면 이동을 멈추고 그 자리에서 **IDLE 애니메이션**을 재생한다.
5. 소년이 **화면 끝(경계)에 도달하면 이동 애니메이션만 유지한 채 더 이상 이동하지 않는다.**
6. 사용자가 `ESC` 키를 누르거나 윈도우를 닫으면 창이 안전하게 닫히고 종료된다.

### 3.2 캐릭터 상태 머신

| 상태 | 전환 조건 | 동작 |
|---|---|---|
| **IDLE** | 이동 중이 아님 (방향키 미입력) | IDLE 애니메이션 재생, 위치 유지 |
| **MOVE** | 방향키 입력 발생 | 해당 방향으로 이동 + 이동 애니메이션 재생 |
| (종료) | ESC 키 또는 창 닫기 | 루프 탈출 및 캔버스 종료 |

* 좌/우 이동: 좌우 방향에 맞춰 **이동 애니메이션** 재생 (왼쪽은 좌우 반전)
* 상/하 이동: **기존 좌우 방향을 유지**하며 이동 애니메이션 재생

### 3.3 상세 규칙

1. **프레임 렌더링 (`clip_draw`)**:
   * 스타터 코드 기준으로 시트의 **런(이동) 행**을 `sheet.clip_draw(frame * 100, 100, 100, 100, x, y)` 형태로 출력한다.
   * 좌우 반전이 필요한 경우 pico2d의 좌우 반전 파라미터를 사용하거나 프레임 좌표를 대칭 처리한다.
   * 캐릭터 프레임은 화면에서 잘 보이는 크기로 출력한다.
2. **이동 처리**:
   * 상태는 `(x, y)` 위치와 이동 방향 벡터로 관리한다.
   * 프레임당 이동 거리(`MOVE_SPEED`)는 `6px/프레임`으로 선정했다.
   * 이동 간 프레임 애니메이션은 순차 증가시키고 `%` 연산으로 순환한다.
3. **경계 제한 (Screen Clamp)**:
   * `x`를 `[0, CANVAS_W - 캐릭터폭]`, `y`를 `[0, CANVAS_H - 캐릭터높이]` 범위로 제한한다.
   * 경계에 닿으면 위치만 고정하고 이동 애니메이션(모션)은 계속 재생하여 '가만히 걷는' 상태를 유지한다.

### 3.4 리소스 명세 (스프라이트 시트 구성)

| 항목 | 값 |
|---|---|
| 시트 크기 | 802 × 402 px |
| 행 구성 | 세로 4행 (y = 0 / 100 / 200 / 300, 행 높이 100px) |
| 행당 프레임 | 8칸 × 100 × 100 px (가로 800px 사용) |
| **IDLE 행** | **y = 200** — 대기 애니메이션 행 (상단 그룹) |
| **RUN(이동) 행** | **y = 100** — 달리기 애니메이션 행 (하단 그룹, 스타터 코드의 `clip_draw(frame*100, 100, ...)`와 일치) |
| **좌우 방향** | 시트에 좌/우 분리 프레임 없음 → 왼쪽 이동은 `clip_composite_draw(..., flip='h')`로 좌우 반전 |

> 행/프레임 구성은 픽셀 분석과 화면 육안 확인을 통해 확정했다.
> 실행 도중 IDLE/RUN 행이 반대로 보이면 상수(`ROW_IDLE`, `ROW_RUN`)만 바꾸면 된다.

## 5. 검증 기준 (Acceptance Criteria)

* [ ] **이동**: 상/하/좌/우 방향키를 누르면 캐릭터가 해당 방향으로 이동하는가?
* [ ] **IDLE**: 방향키를 놓으면 IDLE 애니메이션이 재생되는가?
* [ ] **방향 전환**: 좌/우 이동 시 바라보는 방향(좌우 반전)이 올바르게 바뀌는가?
* [ ] **상/하 이동**: 위/아래로 이동할 때 기존 좌우 방향이 유지되는가?
* [ ] **경계 제한**: 화면 끝에 닿은 캐릭터가 경계를 넘지 않으면서 이동 모션을 유지하는가?
* [ ] **종료**: ESC 키 / 창 닫기로 안전하게 종료되는가?
* [ ] **커밋 이력**: 작업 과정이 기능 단위의 점진적 커밋으로 기록되어 있는가?
